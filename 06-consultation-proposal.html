Consultation Booking Flow

Step 1: Booking

  • Trigger: BDM/CRM clicks "Book Consultation"
  • Required fields: Date, Time slot, Mode (Phone/Video/In-person), Notes
  • Auto-actions: Calendar event created, Customer WhatsApp sent, BDM task created, TL notified

Step 2: Reminders

  • 24 hours before: WhatsApp reminder to customer + Email reminder to BDM
  • 2 hours before: Final WhatsApp to customer + Push notification to BDM

Step 3: Consultation Completion

  • BDM marks "Consultation Done"
  • Required inputs: Duration, Customer Interest Level, Site Visit Required?, Key Discussion Points
  • If site visit required: Create site visit task
  • If no site visit: Proceed to proposal or nurturing

Site Visit System

Booking

Trigger: Consultation done + Site visit required
Assigned to: BDM based on area/pincode
Timeline: Within 3 days of consultation

During Visit - Mandatory Captures

1. Site Photos (min 3)

  • • Roof/terrace photo
  • • Electrical panel photo
  • • Available space photo

2. Site Assessment Form

  • • Roof type (RCC/Sheet/Tile)
  • • Roof condition
  • • Available area (sqft)
  • • Shade analysis
  • • Electrical phase
  • • Structure strength
  • • Any obstacles

3. Customer Interaction

  • • Who was present
  • • Questions asked
  • • Concerns raised
  • • Interest level observation

Post Visit - BDM Actions

  1. Upload all photos to CRM (within 2 hours)
  2. Complete site assessment form
  3. Select Customer Impression: Loved It / Okay / Disappointed / Couldn't Assess
  4. Capture Objections (if any)
  5. Recommend system size
  6. Mark "Site Visit Completed"

Proposal System & Follow-up

Proposal Document Contents

  1. Customer details
  2. Site assessment summary
  3. Recommended system specifications
  4. Pricing breakdown
  5. Subsidy details
  6. EMI calculator
  7. ROI analysis
  8. Warranty information
  9. Company credentials
  10. Terms & conditions
  11. Validity period
