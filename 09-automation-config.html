Zoho CRM Workflow Rules

Workflow 1: Lead Score Calculation

Trigger: When all 8 qualification criteria are filled
  • Calculate total score (max 100 points)
  • Assign temperature tag (HOT/WARM/COLD/JUNK)
  • Auto-assign to appropriate team member
  • Create task sequence based on temperature
  • Send welcome WhatsApp based on score

Workflow 2: 5-Day Attempt System

Trigger: New lead enters CRM
  • Send Welcome WhatsApp (A1) within 5 minutes
  • Create 5 sequential attempt tasks
  • Assign to CRM Executive based on area
  • Set due dates (Day 1, 2, 3, 4, 5)
  • Auto-send WhatsApp after each "Not Connected" outcome
  • Create TL Review task on Day 6 if all attempts fail

Workflow 3: Stage Movement Alerts

Trigger: Lead stage changes
  • Notify assigned owner via push notification
  • Send stage-specific WhatsApp to customer
  • Update last activity timestamp
  • Create next stage task automatically
  • Alert TL for key stage movements

Workflow 4: Consultation Reminders

Trigger: Consultation scheduled
  • 24 hours before: Send WhatsApp reminder (CO2)
  • 24 hours before: Email reminder to BDM
  • 2 hours before: Send final WhatsApp (CO3)
  • 2 hours before: Push notification to BDM
  • If no update 2 hours after scheduled time: Alert TL

Workflow 5: Proposal Follow-up

Trigger: Proposal sent
  • Send proposal delivery WhatsApp (PR1)
  • Create 6 follow-up tasks (Days 1, 3, 5, 7, 10, 14)
  • Auto-send scheduled WhatsApp messages (PR2-PR6)
  • Track WhatsApp engagement
  • Create TL review if no response after Day 14

Workflow 6: Objection Track Enrollment

Trigger: Objection captured in CRM
  • Identify primary objection category (1 of 7)
  • Create 8 weekly tasks for CRM/BDM
  • Schedule 8 weekly WhatsApp messages
  • Set 60-day timeline
  • Create TL review task at end of 8 weeks

Team Leader Approval Gates NEW V2.0

⚠️ 5 Critical Approval Points

Gate 1: 5-Day Attempt Completion

Trigger: All 5 attempts completed, no connection
TL Options: Retry (3 more days) | Move to Cold Nurturing | Mark as Junk
No lead moves without TL action

Gate 2: Junk Classification

Trigger: CRM/BDM requests junk classification
TL Verifies: All attempts made? Any engagement? Reason valid?
TL must approve before archiving

Gate 3: Lost Deal Classification

Trigger: BDM marks deal as Lost
Required: Loss reason, conversation notes, objection details
TL can approve or request recovery attempt

Gate 4: 60-Day Objection Track Completion

Trigger: 8-week objection track completed, no conversion
TL Options: Extend 4 weeks | Move to Cold | Close
Reviews all 8 task + message engagement

Gate 5: Discount/Special Pricing Approval

Trigger: BDM requests discount > 5%
TL Options: Approve | Approve Partial | Reject | Escalate to SM
Documented reason required

WATI Automation Triggers
